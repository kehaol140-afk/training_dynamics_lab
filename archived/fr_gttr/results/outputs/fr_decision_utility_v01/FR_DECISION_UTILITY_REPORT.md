# FR DECISION UTILITY REPORT v01

问题: 完整切线响应能否帮助选择一个真正降低未来验证损失的训练动作，
且该收益是否值得额外计算成本？

## 结论（按 §14 成功标准）

- 条件定位: CONDITIONAL_LOOKAHEAD_LIMITATION: 本实验验证 trajectory-conditioned local counterfactual scoring——完整切线使用给定 baseline future trajectory 的未来梯度/HVP；结果不能解读为'仅从当前状态预测未知未来'的 current-state-only forecast。
- math-SDPA HVP caveat: C/完整切线的未来步 HVP 使用 math-SDPA 代理（native flash-attention 无 double backward），是混合后端解析代理而非精确 flash 核 tangent；与 A0C/A0E2 相同。
- **完整切线响应的任务层训练决策效用已在独立评价数据（V_eval，新 seeds 2038–2041）上得到支持；其相对逐候选真实回放的墙钟成本优势，经独占 GPU 计时补测在 M∈{1,2,4}（H∈{1,4,8}）内未获支持（shared-tangent speedup 恒 <1，无 break-even）。**
- Level 1 局部导数: 成立——formal H=4 完整切线 hhat vs 中心差分 Pearson 0.905、符号准确率 0.88（§14 准则 1）。
- Level 3 决策效用（formal H=4）: 成立——C 的 mean Gain 1.54e-04、Regret 1.04e-04、harmful 0.177、top-1 0.45、组内 Spearman 0.37 全面优于随机/对齐基线（stream 级 p≤0.002；§14 准则 2、3）。
- 决策效用的稳健性（分层审计）: H=4: C vs 随机/对齐 Gain 与 Regret 的 bootstrap P(有利)≥0.96；C vs B 方向一致（Gain P(>0)=0.84、Regret P(<0)=0.85，CI 跨 0，不夸大）。H=8: C vs B 稳健（Gain/Regret 的 CI 不跨 0，P(有利)≥0.995）。
- 计算效率（§12 成本补测）: H=4 M=4: shared-tangent-C total 6.767s vs direct 2.649s（speedup 0.39×）；shared-B 4.736s（0.56×）、direct-fd 4.768s（0.56×）；break-even: H1 shared_tangent_B: M*=无(≤64), H1 shared_tangent_C: M*=无(≤64), H4 shared_tangent_B: M*=无(≤64), H4 shared_tangent_C: M*=无(≤64), H8 shared_tangent_B: M*=无(≤64), H8 shared_tangent_C: M*=无(≤64)。
- §14 判定: 准则 1–4 成立（决策效用）；准则 5（相对逐候选回放的墙钟效率）**不成立**——在本模型规模与计时口径下，shared-tangent 传播不比真实回放更快，决策效用成立不依赖成本结论。

注: 决策效用（A）与计算效率价值（B）分别判定——A 已由独立 V_eval 评价支持；B 由独占 GPU 计时补测单独核验。

## 限制

- CONDITIONAL_LOOKAHEAD_LIMITATION: CONDITIONAL_LOOKAHEAD_LIMITATION: 本实验验证 trajectory-conditioned local counterfactual scoring——完整切线使用给定 baseline future trajectory 的未来梯度/HVP；结果不能解读为'仅从当前状态预测未知未来'的 current-state-only forecast。
