# A0C AdamW m+v Response Theory Design

## Classification and scope

This is an architectural analysis extension: it reconstructs a MiniMind model,
replays registered future batches, obtains the gradient consumed by native
AdamW, and joins a new deterministic theory prediction to the existing A0C
table. It is strictly `[FR-OBSERVATION-ONLY]`: no optimizer step, training,
perturbation, checkpoint write, or modification of existing experiment outputs.

## Fixed inputs

- A0C target: `outputs/a0_fr_audit/v01/direct_path/a0c_state_horizon.csv`
- State checkpoints: `outputs/e3_confirmatory/v07/seed_<seed>/states/state_step_<step>.pt`
- Paired-response manifests: the eight E2 manifests under the matching
  `seed_<seed>/e2_stream_manifests/state_step_<step>/` directory
- Dataset and partition: `outputs/e3_confirmatory/v07/e3c_subset.jsonl` and
  `partition_v07.json`
- Model/runtime configuration: `research/configs/e3c_confirmatory_v07.json`
- Direction requested by the audit:
  `outputs/e1_fluctuation/v03_pilot/probe_direction_q.pt`

Every checkpoint, manifest, and q tensor must match the expected seed/state,
parameter name, and tensor shape. There is no fallback to v06 or another seed.

## A0C response normalization and dimensions

The measured target is generated by

```text
chi(H) = mean_stream[(X_plus(H) - X_minus(H)) / (2 epsilon)]
epsilon = rho * sigma_q
```

Therefore `chi` is already a unit-perturbation susceptibility. If `X` has units
of parameter projection and `epsilon` has units of gradient, `chi` has units
`parameter / gradient`.

The theory compared with `chi` must consequently omit another factor of
`epsilon`:

```text
mu_q = sum_i q_i^2 / (sqrt(v_i) + adam_eps)

nu_q = sum_i q_i^2 * m_i * g_i
       / (sqrt(v_i) * (sqrt(v_i) + adam_eps)^2)

chi_m(H)  = -eta * mu_q * (1 - beta1^H)
chi_mv(H) = chi_m(H) + eta * nu_q * (1 - beta2^H)
```

Both `eta*mu_q` and `eta*nu_q` have the same units as `chi`. For reference only,
the predicted raw paired displacement is `epsilon * chi_mv`; it is not used for
the requested R2/correlation comparison. `rho`, `sigma_q`, and `epsilon` remain
audited metadata and are not fit parameters.

## Gradient replay

For every seed/state and each of its eight E2 streams:

1. Recreate the configured MiniMind model, tokenizer, dataset, native AdamW, and
   GradScaler.
2. Restore the exact full state checkpoint.
3. Seed the future RNG from the E2 manifest's `stream_seed`.
4. Replay only the first optimizer-step batch group: two manifest micro-batches
   because `accumulation_steps=2`. Apply the registered native micro-step LR and
   divide each loss by the accumulation count.
5. Backpropagate, unscale, and apply the configured global gradient clipping.
   The resulting gradient is `g_t`, because it is the gradient native AdamW
   would consume. Do not inject a perturbation and do not call
   `optimizer.step()` or `scaler.update()`.
6. Read raw checkpoint `exp_avg=m` and `exp_avg_sq=v`, align `m`, `v`, `g_t`,
   and `q` by model parameter name/order with exact shape checks, and compute
   `mu_q` and `nu_q` in float64.

`mu_q` is state-specific and identical across streams. `nu_q` is computed per
stream because `g_t` and dropout RNG are stream-specific. The final state-level
`nu_q` is the arithmetic mean across the same eight E2 streams used by the A0C
central-difference mean; no empirical weight or fitted scale is introduced.

## Outputs and validation

Write only a new directory:
`outputs/a0_fr_audit/adamw_mv_response_theory_v01_v07/`.

- `summary.json`: formulas, normalization/units, exact source paths,
  checkpoint/manifest matching, `overall_R2`, `overall_corr`, `seed_R2`,
  `horizon_R2`, and missing-state/stream reports.
- `state_stream_features.csv`: reproducible seed/state/stream `mu_q`, `nu_q`,
  LR, clipping, hashes, and source paths.
- `predictions.csv`: observed `chi`, `chi_m`, and `chi_mv` by
  seed/state/horizon.
- `mechanism_report.md`: answer-first result and explicit dimensional audit.

Validation will cover formula arithmetic, name/shape alignment, manifest hash
and metadata checks, unit-response scaling (no repeated epsilon), stream
averaging, missing inputs, no call to optimizer step, and preservation hashes
for checkpoints and prior v01/v02 outputs. Metrics use predictions directly,
with no regression refit, intercept, or calibration parameter.
